# 多视角 HRRP 目标开集识别：系统性文献调研

检索截止日期：2026-08-06。

本目录按“证据强度”和“任务是否与研究场景同构”组织，而不是按题名中的关键词粗分。

- `研究现状报告.md`：结论、严格纳入边界、直接同题证据卡、发展脉络、baseline 优先级和待解问题。
- `分层文献矩阵.csv`：逐篇结构化信息；`NR` 表示公开证据未报告或本轮无法核验。
- `检索日志.md`：数据库、检索式、引文链、作者/专利/学位论文查漏和停止规则。
- `sources.bib`：核心与代表性文献的 BibTeX 记录。
- `artifact.json`：经数据报告工具验证的摘要型可视报告数据。

## 最重要的边界

“直接同题”必须同时满足：

1. 一个测试样本由同一目标的多条 HRRP 联合构成；
2. 多条 HRRP 在一次判决中被联合使用，而非只做训练增强或逐帧独立统计；
3. 识别对象是目标类别/型号；
4. 测试中包含训练阶段未出现的真实未知类别；
5. 论文报告了已知分类与未知拒识机制或实验。

按该边界，完整实验型核心论文为 JSR-OSR（2022）、JDSR-OSR（2023）和 MtCS-OSR（2024）。Lundén & Koivunen（2016）满足多站联合输入与阈值拒识架构，但公开/已核正文证据未形成“真实未见类别测试”，因此列为直接架构先驱，而不与三篇完整开集实验证据合并计数。
