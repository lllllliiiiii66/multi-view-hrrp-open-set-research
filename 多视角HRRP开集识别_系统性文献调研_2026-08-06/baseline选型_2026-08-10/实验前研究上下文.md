# 随机无序多视 HRRP 开集识别：实验前研究上下文

**版本：2026-08-10；用途：后续 Codex 实现实验的正式依据。**  本文件整合既有 baseline 文献调研与项目 Chat 对话“多视角HRRP识别讨论”的最新决定；它取代此前报告中“以 (V=5) 为主设定”和“第一轮加入重构分支”的建议，但不覆盖此前的文献证据与逐篇核查记录。

## 1. 已冻结的研究对象

- 任务是**目标身份开集识别**：测试时同时完成 7 个已知目标中的型号分类与 3 个未知目标的拒识；7/3 是第一轮暂定类别划分，未知类不得参与训练、早停、超参数选择、OpenMax 尾部拟合或阈值确定。
- 每类数据覆盖完整 (360^\circ)，角度间隔 (1^\circ)，每个角度一条仿真 HRRP。先在各角度域内以连续角度块划分 train/validation/test，再从各自池中构造目标级集合，禁止先组集合后随机切分。
- 主输入为 (S=\{x_1,x_2,x_3\})：从 3 个不同角度域各随机采一条 HRRP，并随机打乱顺序。角度、角度域编号和原始顺序只用于审计与复现实验，**不输入模型**。
- 主研究场景固定 (V=3)。JDSR-OSR 的 (V=5) 只作为论文协议对齐的辅助分支，不能改变主问题、主表或主要结论。
- 当前不把“Deep Sets/Transformer”写成研究问题或创新结论；它们只是检验集合融合假设的 baseline。

> 尚未冻结的不是方法，而是数据构造参数：角度域数量、边界及连续块比例。实现时必须将其显式写入版本化配置；角度域数需不少于 5，才能支持 JDSR 的 (V=5) 辅助实验。

## 2. 研究问题与受控比较

| 研究问题 | 主比较 | 能回答什么 | 不能过度解释什么 |
|---|---|---|---|
| R1：多视是否有效 | B0 → B1 | 同一单视模型下，增加到 3 个随机视图并做最简单决策融合的净收益 | 不能据此证明学习式集合建模有效 |
| R2：融合层级有何作用 | B1 → B2 → B3 | 决策平均、集合特征均值、显式跨视角交互的递进作用 | B1 与 B2 还包含“是否进行集合级训练”的差异，需结合参数量与训练曲线解释 |
| R3：OpenMax 应放在融合前还是融合后 | B1/B4 与 B2/B5 构成 2×2 对照；重点看 B4 ↔ B5 | 单视 OpenMax 后融合与集合表征后 OpenMax 两条完整迁移 pipeline 的优劣 | B4 ↔ B5 不是纯粹只改变判决时刻；必须结合 B1↔B2、B1↔B4、B2↔B5 联合归因 |
| R4：直接方法处于什么位置 | B6 ↔ B4/B5（主 (V=3)）；辅助 (V=5) 同样比较 | JDSR 的联合稀疏重构与双尾 EVT 相对两类深度迁移方案是否仍有优势 | 本数据不是原论文数据，不能把结果表述为对论文数值的精确复现 |

## 3. 第一轮 baseline 统一方案

| Baseline | 输入、融合与开集判决的正式定义 | 论文依据 | 验证目的 | 优先级 |
|---|---|---|---|---|
| **B0：Single-view CNN + MSP/Energy** | 统一 1D-CNN 处理单条 HRRP；MSP 未知分数为 (1-\max p_k)，Energy 按统一温度计算。测试时对每个三视集合按固定种子均匀抽 1 条，分别重复并平均**指标**，不平均预测 | MSP/Energy 通用基线；共享 HRRP CNN 骨架 | 给出不使用多视信息的分类与拒识下限 | **P0** |
| **B1：Late Fusion + MSP/Energy** | **复用 B0 权重**；分类后验为 (\bar p=\frac{1}{3}\sum_v p_v)，MSP 基于 (\bar p)；Energy 采用逐视 Energy 的均值。无集合级训练 | Lundén & Koivunen, 2016，DOI: [10.1109/RADAR.2016.7485271](https://doi.org/10.1109/RADAR.2016.7485271) | 以最小改动测量多视数量和决策平均的收益 | **P1** |
| **B2：Deep Sets + MSP/Energy** | 共享 1D-CNN 后做 mean pooling，再用集合分类头；无角度/位置编码，端到端集合训练 | Zaheer et al., 2017；[官方代码](https://github.com/manzilzaheer/DeepSets) | 检验严格置换不变的集合特征融合是否优于决策融合 | **P1** |
| **B3：Set Transformer + MSP/Energy** | 同一 1D-CNN；无位置/角度编码的 SAB/ISAB + PMA，端到端训练 | Lee et al., 2019；[官方代码](https://github.com/juho-lee/set_transformer)；Guo et al., 2023 的无角度多站融合证据，DOI: [10.12000/JR23014](https://doi.org/10.12000/JR23014) | 检验显式跨视角交互相对均值集合统计的作用 | **P1** |
| **B4：Per-view OpenMax + 决策融合** | **复用 B0 权重**；对每个视角分别做 OpenMax，得到 (K+1) 后验，再等权平均；以平均未知概率拒识。主结果不用“先硬拒识再投票” | Chen et al., 2019 单视 HRRP OpenMax，DOI: [10.1049/joe.2019.0706](https://doi.org/10.1049/joe.2019.0706)；Lundén 式后验融合 | 测试成熟单视 HRRP 开集方法直接逐视迁移是否有效 | **P2** |
| **B5：Deep Sets + OpenMax** | **复用 B2 checkpoint**；在集合级激活上重新估计类中心和 Weibull，产生集合级未知概率。不得复用 B4 的单视 OpenMax 参数 | Chen et al., 2019 + Deep Sets | 与 B2 只差后处理开集头；并与 B4 比较“先拒识后融合”与“先融合后拒识”两条 pipeline | **P2** |
| **B6：JDSR-OSR** | 按联合动态稀疏表示、联合重构选类和双尾 GPD 实现；主结果适配 (V=3)，辅助结果用 (V=5) 对齐原论文 | Liu et al., 2023，DOI: [10.11999/JEIT221284](https://doi.org/10.11999/JEIT221284) | 与最接近的直接多视 HRRP 开集方法比较 | **P3** |

结论：**B0–B6 均为第一轮强烈推荐，且已构成最小充分集合；没有明显的方法族缺口。** BDC、CFRPL、重构、伪未知和更多稀疏方法暂不加入。它们只有在第一轮暴露出明确失败模式后才进入第二轮。

## 4. 必须修正或补充的实施口径

1. **主视角数改为 (V=3)。** 既有调研报告中的 (V=5) 主设定已被最新研究讨论覆盖；(V=5) 仅保留为 B6 论文对齐实验，并至少同步报告 B4/B5 的 (V=5) 结果。
2. **B0 不可任取“第一个视角”。** 输入是无序集合，不存在语义上的第一项；B0 应以固定种子抽取单视并跨重复平均指标，确保既不利用三视融合，也不引入位置偏差。
3. **B1 固定为真正的决策级融合。** MSP 使用平均后验，Energy 使用逐视分数平均；不要在不同实验中混用“平均 logit 后算 Energy”等未预注册变体。
4. **B4 采用软融合。** 先将每视角校准为 (K+1) 后验，再平均；硬拒识投票会额外引入投票规则和信息损失，只能作为诊断项。
5. **B5 必须在集合激活上独立校准。** 单视和集合表征分布不同，二者不可共享 MAV、Weibull 或 tail 参数。
6. **B4 ↔ B5 是 pipeline 对照，不是单一原子操作对照。** 其解释必须同时参考 B1↔B2（融合表征）、B1↔B4 和 B2↔B5（开集头）的结果。
7. **B6 的公平结果与论文保真结果分开。** 主表采用相同底层角度划分和仅用已知验证集确定的阈值；论文固定参数作为辅助诊断。由于代码和原始数据未公开，只能称“核心算法复现/适配”。

## 5. 统一训练与评价协议

- **共享性：** B0/B1/B4 复用同一单视 checkpoint；B2/B5 复用同一 Deep Sets checkpoint；B3 使用同构 1D-CNN encoder。各可训练模型使用相同初始化种子集合、优化器、epoch/early-stop 预算、数据增强和已知类监督。B3 额外参数与 FLOPs 必须单列，不能假设与 B2 完全等参。
- **阈值：** 所有方法统一定义“越大越未知”的目标级分数。主 operating point 在已知 validation 上取 95% 接受率对应阈值；未知类不参与选择。AUROC、OSCR 与 FPR95 同时报告，避免单一阈值掩盖排序能力。
- **OpenMax：** 只用分类正确的已知训练样本拟合尾部；tail size、alpha 和距离度量使用同一预注册网格，并只依据已知 validation 的校准稳定性选择。
- **JDSR：** 字典只能由已知训练 HRRP 构建；公平阈值只用已知 validation。原文固定 (J=5) 的分支单独标注“paper-aligned”。
- **指标：** 已知类 Accuracy/Macro-F1；AUROC、OSCR、FPR95；固定阈值下的 (K+1) Macro-F1、已知接受率和未知拒识率；同时报告参数量、FLOPs、推理时间，JDSR 另报字典规模和求解时间。
- **重复性：** 先固定类别划分、角度块划分和集合采样种子；主结果报告多随机种子的均值与置信区间。对所有 (V=3) 集合穷举 (3!=6) 种排列做不变性审计；B1/B2/B3/B4/B5 的输出应在数值容差内一致。

## 6. 文献一致性与证据边界

- B1 与 Lundén 2016 的“各通道独立 CNN + 后验平均 + 最大概率阈值”结构一致，但原论文没有足够证据支持真实未见类别的完整 OSR 结论，因此只能称 **Lundén-style**。
- B2/B3 分别由 Deep Sets 与 Set Transformer 的置换不变集合建模支撑；Guo 2023 只提供 HRRP 闭集、多站和无角度 Transformer 融合的领域证据，其完整角度引导模型不进入本研究主 baseline。
- B4/B5 是对 Chen 2019 单视 HRRP OpenMax 的两种受控迁移，不是原论文的原样复现。
- B6 是当前链中唯一直接针对“多条 HRRP 联合输入 + 已知分类/未知拒识”的已发表主对照；原论文固定 5 视和随机角度情形与本场景最接近，但并未证明完整方位域随机集合下的严格置换不变性。
- Deep Sets 与 Set Transformer 有作者公开代码；Lundén HRRP 融合、Chen HRRP OpenMax、Guo HRRP Transformer 和 JDSR 均未定位到作者公开的可直接复现实验代码。代码公开性影响复现成本，不改变其在消融链中的逻辑角色。

## 7. 实施顺序

1. **P0：** 冻结数据配置、泄漏检查、统一 1D-CNN、B0 与评价器。
2. **P1：** 用 B0 checkpoint 完成 B1；随后实现 B2、B3，先回答 R1/R2。
3. **P2：** 基于既有 B0/B2 checkpoint 增加 B4/B5，只做校准与判决层工作，回答 R3。
4. **P3：** 实现 B6；先跑主 (V=3)，再跑 B4/B5/B6 的 (V=5) 辅助对齐，回答 R4。

该顺序保证每一阶段即使提前停止，也已有一条可解释的控制链；任何新增方法必须先说明它填补了哪一个尚未被 B0–B6 覆盖的问题。
