- 前向：OpenAlex 返回 81 篇引用工作；Aalto 页面在检索日显示 Scopus 96 次引用。逐题名筛查后，相关工作主要落入单站 HRRP、雷达传感器网络闭集识别、多站 Transformer/图融合或其他雷达模态，没有发现新的严格 A0。

## 四、两轮扩展检索

第一轮：围绕种子题名、作者、方法缩写 JSR/JDSR/MtCS、专利和中文同义词扩展。  
第二轮：使用 multistatic、radar sensor network、unknown rejection、out-of-library 等宽检索式交叉验证。

第二轮新增结果主要是：

- 多站 HRRP 闭集方法（A2）；
- 单站连续方位角的多视开集方法（A1）；
- HRRP+ISAR 多源模态开集方法；
- 单站最新 HRRP 开集边界方法；
- RCS、微多普勒、ISAR/SAR 等非 HRRP 网络雷达方法。

没有新增严格 A0，达到本轮停止条件。

## 五、容易误收的文献

- `Open-set HRRP recognition method based on joint sparse representation`：摘要明确是**单站观测**。
- `Open set target recognition based on multi-task compressed sensing...`：可访问摘要只说小角度区间多个观测，没有多站/多基地证据。
- `Multi-view Polarization HRRP...`：多视/多极化，不是多个雷达站。
- `Research on Target Recognition Method Based on Multi-Source Information Fusion`：HRRP+ISAR 两种模态，不是多站多个 HRRP。
- `BiGRU-Transformer and Dual Graph Fusion Network`：网络雷达输入为多频多角 RCS 序列，不是 HRRP。
- 缺失方位、HRRP 序列生成、单站角度组方法：可为多视建模提供工具，但不进入 A0。
