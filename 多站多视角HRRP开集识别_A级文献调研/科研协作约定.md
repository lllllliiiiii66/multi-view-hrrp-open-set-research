# 科研协作约定

本文档用于统一本课题的研究要求、工作节奏和文档维护方式。课题事实以研究锚点和实验文档为准，不在本文重复记录。

## 一、研究原则

1. 研究过程应逐步推进。每一阶段只解决当前最关键的问题，不在研究初期提前展开次要细节。
2. 先明确研究场景和问题，再调研直接相关文献、分析现有方法及其问题，最后依据证据确定技术路线。不能预先假定创新点。
3. 对方法问题的判断必须区分实验现象、直接原因和可能解释。没有论文或实验依据时，不作确定性结论。
4. 保持客观、严谨。既不为了支持预设思路选择证据，也不把尚未验证的推测包装成研究结论。
5. 优先保证研究工作的有效性。只有在核心方法和主要问题明确后，再讨论视角顺序、样本重叠、角度难度、可变视角数等补充问题。

## 二、研究边界

本课题中的“多视角HRRP”是指同一目标在不同方位角下的多个HRRP被联合用于一次目标判决，不限定数据必须来自单站、多站或特定雷达体制。

研究问题是开集识别，即同时完成已知目标分类和未知目标拒识。单HRRP开集识别、多视角闭集识别和多模态雷达识别属于邻近研究，不能替代直接多视角HRRP开集识别证据。

## 三、文献调研要求

1. 直接相关文献应尽可能充分检索，并进行题名、作者、参考文献和引用关系追踪。
2. 每篇核心文献重点记录：模型或网络架构、损失函数或优化目标、多视角联合方式、开集拒识机制、主要实验结论与局限。
3. 明确区分全文证据、摘要证据和推断。无法核实的内容标记为“待核验”，不得自行补全。
4. 区分直接相关方法、邻近方法和同一方法的论文、会议版本或专利，避免重复计算研究成果。
5. 关于现有方法问题的结论应能够回溯到具体文献、实验结果或明确缺失的关键实验。

## 四、文档职责

- **研究锚点**：按照论文初稿的标准记录已经确认的研究背景、研究问题和核心逻辑。内容应稳定、精炼，不记录调研过程和临时设想。
- **实验文档**：记录已经确认的核心实验方案和任务定义。未确定的方法、参数、指标和补充实验不提前写入。
- **文献调研表**：持续记录文献检索和方法分析结果，可以随证据增加而更新。
- **科研协作约定**：只规定工作方法和文档维护原则，不承担研究内容记录功能。

研究锚点和实验文档属于课题核心文档。修改前应先给出准确的修改内容供预审，确认后再写入；不因一般讨论频繁改动。

## 五、表达要求

1. 使用准确、精炼、可读的科研语言，达到论文写作的基本要求。
2. 优先讲清主线，避免为了显得完整而堆叠层级、问题和实验细节。
3. 术语、研究边界和符号应保持一致，使其他模型或研究者阅读核心文档后能够准确理解课题。
4. 明确区分已确认内容、工作假设和待解决问题，避免含混表达。
5. 结论先于展开说明；能够用一段话讲清的内容，不拆成冗长列表。

## 六、协作方式

1. 每次讨论聚焦一个紧邻的研究步骤，未经确认不把工作推进到过远阶段。
2. 当用户认为分析过细或过于复杂时，应立即回到当前核心问题，而不是继续扩展细节。
3. 新结论与既有文档不一致时，先说明变化依据，再决定是否修改核心文档。
4. 阶段性产出应说明哪些内容已经确认、哪些仍是证据缺口，以及下一步最小且有效的工作是什么。
