# P0 AMDR 正式输入数值域冻结记录

> 日期：2026-08-30
>
> 阶段：P0
>
> 结论：正式输入冻结为逐条 HRRP 峰值相对线性功率，不再把该变换仅标记为 smoke 稳定化措施。

## 1. 已确认的数据事实

`TrcsHH` 是功率 dB，定义为 `10*log10(power)`；该结论已经由原始 `Ep` 重算验证。601 维处理后 bundle 先在线性功率域生成固定均值功率为 `-140 dB` 的复高斯噪声，再转回功率 dB 与原始 bin 拼接。

处理后 3,600 条 profile 的总体范围为 `-199.1497–72.3633 dB`。逐条检查原始区与补齐区后，所有 profile 的最大值都位于原始区，没有一条由补齐噪声决定归一化峰值。

师兄舰船附件训练数据的两个视角均为非负数，范围约为 `4e-6–1`，且每条训练 profile 的最大值为 1；论文正文也明确说明对原始 HRRP 做归一化以抑制幅度敏感性。附件没有给出完整生成脚本，因此这里把它作为尺度证据，而不是逐数值复现目标。

## 2. 冻结变换

对每一条完整的 601 维功率 dB profile 独立计算：

\[
x_{\mathrm{rel}}=10^{(x_{\mathrm{dB}}-\max_j x_{\mathrm{dB},j})/10}
=\frac{p}{\max_j p_j}.
\]

稳定标识为 `power_db_to_peak_relative_power_v1`。输出为 `float64` 峰值相对线性功率，每条 profile 最大值严格为 1，不再进行总体均值方差标准化、逐 bin 标准化或 L2 归一化。

该变换不拟合任何训练、calibration 或 test 总体统计，因此不会把跨 split 信息带入模型。它去除逐条 profile 的统一 dB 偏移，保留相对散射功率形状，并把 AMDR 输入限制到稳定尺度。

真实 bundle 的机械检查结果为：所有输出有限且严格大于 0；最小值约 `1.46e-24`；fold 0 已知训练底层 HRRP 的 L2 范数范围约为 `1.015–3.089`，中位数约为 `1.266`。

## 3. 选择边界

本决定依据物理数值定义、参考附件尺度和数值稳定性冻结，没有使用未知类或最终 test 的识别指标比较候选变换。直接使用 dB 会把对数域差值当作线性欧氏几何；使用未归一化绝对线性功率则会保留巨大的跨 profile 尺度差异。二者当前均不进入正式候选。

这一变换不会消除已经接受的 `profile_length_role_shortcut_v1` 风险：不同原始长度造成的补齐边界仍可能泄露类别角色。该风险继续单独报告，不能把由此获得的未知拒识能力解释为 AMDR 开集机制的有效性。
