> 日期：2026-08-30
>
> 阶段：P0
>

## 1. 固定方法边界

`amdr_research_v1` 保留三项核心结构：多视角判别回归、每个视角独立的类内自适应流形关系，以及按视角投影行稀疏度更新的全局视角权重。第一阶段固定两个有序视角槽位，不宣称置换不变。

两条 601 维 HRRP 先按 `power_db_to_peak_relative_power_v1` 转为峰值相对线性功率，再沿特征维连接。模型学习连接投影矩阵 `W_tilde`，两个视角块在类别判别空间中相加，得到维度等于已知类数的联合投影。

标签使用 `+1/-1` 判别回归编码。非负松弛矩阵用于扩大正确类别方向和错误类别方向的回归间隔。每个视角、每个已知类别分别维护零对角、行和为 1 的自适应关系块，关系权重与当前投影平方欧氏距离的倒数成正比。

## 2. 明确的实现选择

- 更新顺序固定为 `M -> W_tilde -> S -> alpha`；这是版本规范，不再声称与论文伪代码逐行一致。
- `l2,1` 行重加权矩阵每次迭代都由上一轮 `W_tilde` 更新，修正附件只初始化一次的问题。
- 所有视角、所有类别的关系块都进入收敛量；附件只检查第一个视角的行为不沿用。
- 关系矩阵只保存精确类内块，不保存跨类全零区域；数学结果与对应的全局块对角矩阵一致。
- 线性方程加入固定 `solve_ridge`，只作为可记录的数值稳定项。
- 初始化使用显式随机种子；后续需要多种子报告初始化不确定性。

联合目标按每一完整轮结束后的当前状态记录为：判别回归损失、加权自适应流形损失和按 `1/alpha_k` 加权的 `l2,1` 稀疏损失之和。实现保存三个分项和总目标，但不把目标单调性当作未经验证的理论保证。

## 3. 停止与 checkpoint

正式收敛量为 `relative_state_change_v1`：分别用上一轮状态的平方范数归一化 `W_tilde`、全部 `S` 块、调整目标和 `alpha` 的平方变化，再求和。它比附件的绝对变化和更适合比较 `n=700/3500/14000` 三种规模。

只有达到 `minimum_iterations` 且相对状态变化低于 `tolerance` 时才停止，否则运行到 `max_iterations`。停止不使用 calibration Accuracy，也不保存性能意义上的“最佳”模型。latest-only checkpoint 只用于中断恢复，恢复关键签名绑定算法版本、收敛规则、训练数据值与顺序。

## 4. 证据边界

师兄论文中的公式下标、联合凸性表述和代码更新顺序存在不一致；附件还存在测试集选择超参数等问题。因此，后续结果应表述为“基于组内 AMDR 思想实现的 `amdr_research_v1`”，而不是论文数值复现。

当前 `lambda_manifold=lambda_sparse=0.01` 只作为首次收敛诊断和 pilot 的参考设置。正式 P1 如需选择正则参数或 K，候选集合与规则必须提前登记，并且只能使用当前 fold 的已知 calibration，不能查看未知或最终 test 后调整。
